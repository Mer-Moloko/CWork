# Ответы
1. int — 4 байта, long long - 8 байт; верхняя граница int - 2147483647.
2. Потому что в C++ переполнение знакового целого — неопределённое поведение, но на практике компилятор просто выполнил сложение по модулю 2^32 без проверки и без остановки.
3. 0, потому что 0.1, 0.2 и 0.3 не представимы точно в двоичной плавающей точке, и 0.1 + 0.2 даёт не ровно 0.3.
4. Первое напечатает 49 (символ '0' имеет код 48, 48+1=49 как int), второе напечатает '1' (static_cast<char> превращает 49 в символ). Разница — в типе результата: int vs char.
5. Ошибка компиляции: переменную const нельзя изменять после инициализации.
6. static_cast<int>(-2.7) = -2, static_cast<int>(2.7) = 2; работает правило отбрасывания дробной части (усечение к нулю), поэтому «по модулю» одинаково.

# Исправление кривых программ
1. Программа выдает ошибку ```error: expected ';' after expression```
Ошибка заключается в отсутсвии ";"
2. Программа выдает ошибку ```error: expected '}'```
Ошибка заключается в отсутсвии "}"
3. Программа выдает не верный ответ ```Стоимость: 350 руб```
Ошибка логическая.

# Программа визитка
Код: ```#include <iostream>
int main()
{
    std::cout << "Иван" << '\n';
    std::cout << "ИС-31" << std::endl;
    std::cout << "Информационные системы и программирование" << '\n';
    std::cout << "2 курс" << std::endl;
    return 0;
}```

Вывод: ```Иван ИС-31 Информационные системы и программирование 2 курс```

# Программа рамка
Код: ```
#include <iostream>
#include "frame.h"
int main() {
std::cout << "********************" << std::endl;
std::cout << "********************" << std::endl;
std::cout << "***** " << "Гущюс" << " *****" << std::endl;
std::cout << "********************" << std::endl;
std::cout << "********************" << std::endl;
    return 0;
}```

Вывод: ```******************** ******************** ***** Гущюс ***** ******************** ********************```

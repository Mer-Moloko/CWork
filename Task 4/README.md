# Повторение и контрольная точка
Ответы на вопросы:
1. `//` — строчный комментарий (до конца строки), `/* … */` — блочный (может охватывать много строк); `//` удобнее для коротких пояснений, `/* */` — для длинных блоков и временного «выключения» кода.
2. `5+3=8`
3. `endl` выводит `\n` и дополнительно сбрасывает буфер потока (flush); похожи тем, что оба переводят строку.
4. Синтаксические — до запуска (компилятор не собирает); ошибки компоновки/линковки — на сборке; логические и ошибки времени выполнения — после запуска (неверный результат или падение).
5. `7 / 2 == 3`; `7 % 2 == 1`; `125 % 60 == 5`.
6. `7 / 2` — целочисленное деление (оба операнда int) → `3`; `7.0 / 2` — деление с плавающей точкой (7.0 — double) → `3.5`.
